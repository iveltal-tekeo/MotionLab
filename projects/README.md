# projects - your videos

One folder per video you make: put your own clips in `projects\<name>\` (the lab only reads them); everything the lab
makes for it goes to `projects\<name>\build\` (frame caches, the edit `edit_vN.py` -> `plan_vN.json`, renders, the
DaVinci Resolve rebuild). In the app this is the **Videos** page. Edits are made with Claude Code
("edit my clips in projects\<name> in the style of <reference>").

Nothing in this folder is uploaded to GitHub (see `.gitignore`).
