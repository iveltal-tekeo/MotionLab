# refs - reference videos

Put the videos you want to study here (other people's music videos, shorts, ads, documentaries ...), or use
**References > Download from a link** in the app (yt-dlp). The lab only ever reads them; its analysis goes to
`analysis\<video name>\`. Audio-only downloads land in `refs\audio\`.

Nothing in this folder is uploaded to GitHub (see `.gitignore`).
